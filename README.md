# Luznaencruzilhada

Statistical analysis for the PIC (undergraduate research) project developed at UNIFECAF.

## Contents

| File | Description |
|---|---|
| `gmf_luz.R` | R script: imports the survey results, derives variables (e.g. chronic disease flag, PHQ-9 depression-risk categories) and produces descriptive statistics and plots |
| `Luznaencuzilhada_gmf.ipynb` | Notebook with the study flow diagram (Graphviz) |

## Requirements

R with `readxl`, `dplyr` and `ggplot2`; Python with `graphviz` for the notebook. The survey data are not included in this repository, so update the input path in `gmf_luz.R` to run it on your own copy.
